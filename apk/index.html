Planetshine 星球放晴

Test build for Android phones and tablets.
Android 手機與平板的測試版。

Download for Android · 下載
  1. Tap the button. If the phone warns that this kind of file can be harmful, choose Download anyway.
    按下按鈕。手機若提醒「此類檔案可能有害」，選 仍要下載。
  2. Open the downloaded file. The first time, allow this browser to install apps when asked, then come back.
    打開下載的檔案。第一次會請你允許這個瀏覽器安裝應用程式，允許後再回來。
  3. Tap Install, then open Planetshine. A newer build installs over the old one and keeps your progress.
    按 安裝，然後打開星球放晴。之後的新版直接覆蓋安裝，進度會保留。
